# Project Plan

## SDP I Objective

Develop and apply the initial tools needed for satellite-image change detection using existing labelled datasets. If feasible, carry out a small Abu Dhabi case study using weak or self-supervised segmentation methods.

The work in SDP I should build the foundation for the core change and anomaly detection task in SDP II.

## Initial Milestones

| Milestone | Main activities | Owner | Status |
| --- | --- | --- | --- |
| Targeted literature review | Review satellite imagery, segmentation, anomaly detection, and environmental monitoring methods. | Week 1-3 | Started |
| Dataset and resource investigation | Identify suitable labelled datasets, Abu Dhabi data sources, and available computing resources. | TBD | Not started |
| Data preparation baseline | Investigate timestamps, image alignment, missing observations, and basic synchronization. | TBD | Not started |
| Segmentation investigation | Compare suitable general-purpose and satellite-image segmentation models. | TBD | Not started |
| Initial change-detection experiments | Combine segmentation outputs and compare regions across time while considering environmental noise. | TBD | Not started |
| SDP I review | Summarize progress, limitations, results, and the recommended next steps. | TBD | Not started |

## Technical Tracks

1. Data preparation and synchronization
2. Segmentation models
3. Combining methods and detecting change
4. Landmark detection and regions of interest
